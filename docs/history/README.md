# MAIW Architecture History

This directory contains historical documents — migration plans, phase-specific specs,
and pre-v2 architecture records — that explain how MAIW got to its current state.

These documents are preserved for lineage and context but do **not** describe how MAIW
works today. For current-state architecture, see [`docs/architecture/`](../architecture/).

## Categories

| Directory | Contents |
|---|---|
| [`mcp/`](mcp/) | Pre-SDK custom MCP implementation and v2 migration artifacts |
| [`modernization/`](modernization/) | Phase-by-phase migration plans and gap analyses |
| [`ui/`](ui/) | Historical UI design specs (Command Center v2) |
| [`agent-runtime/`](agent-runtime/) | Pre-AgentRuntime reasoning engine records |
| [`CURRENT_ARCHITECTURE.md`](CURRENT_ARCHITECTURE.md) | Static snapshot from commit `e33ed69` — LangGraph-based pre-v2 architecture |
